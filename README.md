# Campfire Composer

Make music for your game. No instruments or experience needed.

Campfire Composer runs entirely in your web browser. There's no account, no install and no server. Your songs stay on your own device.

**Play it:** open the GitHub Pages link for this repository.

## On an iPad or iPhone
- Open the link in Safari, tap **Share**, then **Add to Home Screen**. It opens full screen like an app.
- One finger draws notes on the grid. Two fingers scroll it.
- Use **Save** now and then to keep a `.campfire` file in Files. Safari can clear website storage you haven't used in a while.

## Saving and sharing songs
- Songs autosave in the browser you're using ("Your songs" on the start screen).
- **Save** makes a `.campfire` file that holds everything, including sounds you recorded or uploaded. Send it to a friend, and they can open it with **Open**.
- **Export** gives you WAV, MP3, MIDI, stems, or a game-ready pack with seamless loops.

## Run it offline on a computer
Download this repository (Code → Download ZIP), unzip it, and open `index.html` in Edge or Chrome.
